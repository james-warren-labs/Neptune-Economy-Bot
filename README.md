# probable-carnival

Node.js Discord bot scaffold by James.

## Architecture

This project uses a modular Node.js/Discord.js structure inspired by the organization patterns seen in RayExo/MusicBot, without copying its source code.

## Run

```bash
npm install
cp .env.example .env
npm start
```

Set `DISCORD_TOKEN` and `CLIENT_ID` in `.env` before starting the bot.
